让灵敏度接近你的游戏

填写鼠标实际 DPI，以及转一整圈需要移动的厘米数（cm / 360°）。后者越大，灵敏度越低。本版按 360 × 2.54 ÷ (DPI × cm) 计算每个鼠标计数对应的角度。

视野设置是 16:9 基准水平 FOV；改变窗口比例时保持垂直视野不变。原始输入是否可用由浏览器与系统决定，不能保证与原游戏的手感完全相同。建议使用鼠标、开启浏览器硬件加速，并实测校准。

自定义训练配色

首页「场景配色」可分别修改小球颜色与训练背景。点击色块打开取色器，预览会立即更新；两种训练模式均使用这套配色，下次打开也会保留。背景保留网格与明暗层次，实际小球也有光照，因此不会是完全均匀的纯色。

「恢复默认」只重置小球和背景颜色，不影响灵敏度、准星或历史成绩。颜色太接近时会提示你提高对比度。

浏览器与兼容模式

推荐电脑端 Chrome / Edge / Firefox，以 HTTPS 或 localhost 打开。嵌入预览可能禁止锁定鼠标，请打开部署后的独立页面。也可切换「光标点靶」：直接点击目标，不转动视角，DPI 与 cm / 360° 在该模式下不生效；两种输入方式的最佳成绩分开记录。

只有你自己的记录

仅在当前浏览器保存最近 50 次完整训练与各模式历史最佳；不登录、不上传、不使用统计脚本。可以导出 JSON 备份，清除网站数据会删除记录。平均命中间隔只计算相邻命中之间的训练时间，不含暂停。

这是独立实现，并非 Aimlabs 官方移植。目标尺寸、布局与计分经过简化，分数不与原版互通。
